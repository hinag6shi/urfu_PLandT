### Как вводить
```
<Дервео> -- вводиться само дерево
```
### `<Дерево>`:
#### К примеру _дерево_:
`8 3 1 -1 -1 6 4 -1 -1 7 -1 -1 10 -1 14 13 -1 -1 -1`
#### Выглядит так:
```
    8
   / \
  3   \ 
 / \   10
1   6    \
   / \    14
  4   7   /
         13
```

### Задача 1 — Построить симметричное дерево
#### Ввод:
```
8 3 1 -1 -1 6 4 -1 -1 7 -1 -1 10 -1 14 13 -1 -1 -1
```
Исходное дерево
```
8(3(1,6(4,7)),10(_,14(13,_)))
```
#### Вывод. Зеркальное дерево:
```
8(10(14(_,13),_),3(6(7,4),1))
In-order:
14 13 10 8 7 6 4 3 1
```
Зеркальное: `8 10 14 -1 13 -1 -1 -1 3 6 7 -1 -1 4 -1 -1 1 -1 -1`
```
       8
    /     \
   10      3
  /       / \
 14      6   1
  \     / \
   13  7   4
```

### Задача 2 — Подсчитать количество максимальных элементов
#### Ввод:
```
5 9 3 -1 -1 9 -1 -1 9 -1 -1
```
Исходное дерево
```
5(9(3,9),9)
```
#### Вывод:
```
max el: 9
number of occurrences: 3
```
